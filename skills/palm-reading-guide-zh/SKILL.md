# 素掌纪｜Palm Editorial（手相解析指南生成工作流）

收到触发请求后直接执行以下四步，不要反问澄清性问题（缺什么特征就如实写"不可辨"）。

## Step 1 读图 · 固化六个特征字段

按顺序尝试，任一成功即停止：

1. 内置识图 `image` 工具（最快）
2. `autoglm-image-recognition` skill：本地图片先用其 `upload-mix.py` 换取公网 URL，再调 `image-recognition.py`

识图 prompt 必须要求**中性形态描述**（禁止让模型给吉凶结论），并回填下表六要素。识别失败的字段写 `不可辨`，严禁编造精确细节：

| 字段 | 记录内容 |
|------|----------|
| `hand_shape` | 掌面偏方/偏长、厚薄、整体轮廓 |
| `finger_ratio` | 手指与掌面比例、粗细、指尖形状（尖/圆/匙形） |
| `life_line` | 起点、弧度宽窄、深浅、是否连续 |
| `head_line` | 与生命线起点关系、走向（平直/下斜）、长度、末端形态 |
| `heart_line` | 起止方位、弧向（上弯/平直/下垂）、连续性 |
| `minor_lines` | 命运线/太阳线/婚姻线等是否可见 |
| （附加）`light_angle` | 光线、角度、清晰度——决定哪些区域"无法辨认" |

## Step 2 文案 · 词典映射，禁止吉凶断语

打开 [references/palmistry-dictionary.md](references/palmistry-dictionary.md)：

- 手型对照四型表定位（多为混合型，主次各写一半句）
- 每条主线按"照片所见 → 解读方向 → 描述句式"映射成稿，句式力求贴合用户真实纹路
- 综合解读按五维框架各写 1–2 句：性格、事业、感情、财运、健康，每维给一个关键词短语

红线（无条件遵守）：

- 禁用词：注定、必然、凶、煞、克、灾、病根、离婚、破产，以及一切绝对化断言
- 全部落点都是"气质与倾向"，不是"命运预测"
- 结尾固定携带免责句：`✳ 内容源自传统掌纹文化的视觉化演绎，仅供文化娱乐参考`
- 用户追问健康/重大决策时，只能复述"倾向描述"+免责句，不给任何现实建议

语气基准：简洁、有质感、略带高级感——像品牌白皮书，不像地摊命理书。

## Step 3 交付 · 默认双通道同发

**通道 A（主力，默认启用）：HTML 白皮书**

1. 复制 [assets/report-template.html](assets/report-template.html) 为独立交付文件
2. 将全部 `{{占位符}}` 替换成 Step 2 成稿（列表类占位符填 `<li>` 片段）
3. 交付 `.html` 原文件；需要静态图片时用浏览器截图导出 PNG

通道 A 承载全部长文案，零中文乱码风险。**不得跳过通道 A 只发生图。**

**通道 B（可选）：AI 生图整页卡**

仅当用户明确要"一张完整的 AI 生成图"时启用：

- 按 [references/image-prompt-template.md](references/image-prompt-template.md) 模板一组装提示词
- 图内每块文字 ≤12 个汉字、全文块数 ≤6，超出部分坚决移交通道 A

**线稿插图（两个通道都需要）：**

- 首选：模板二的"黑白线稿手掌示意"提示词交给文生图模型直出
- 兜底/快速路径：直接使用 HTML 模板内置 SVG 示意图（已标注三大主线位置，零外部依赖）
- 密集中文标注永远不在生图阶段完成——由 HTML/CSS 层叠加

## Step 4 中文社区排版十条（两通道共用自查清单)

1. 竖版 3:4（小红书/公众号封面友好）；做手机长图时 9:16
2. 纯白底 `#FFFFFF`，主字墨黑 `#111`，辅灰 `#666`/`#999`，至多一种点缀色（暖金/朱砂二选一）
3. 细线条 ≤1px，圆角卡片 12–16px，分区留白充足
4. 中文标题衬线字体（宋体/Noto Serif SC），正文细黑体（PingFang SC/Helvetica Neue）
5. 章节 `01 / 02 / 03` 数字编号，营造杂志目录感
6. 克制的信息密度：每卡要点 ≤3 条、每条 ≤24 字
7. 卡片内不出现任何宿命断语（连玩笑都不行）
8. 页尾或右下角固定「仅供文化娱乐参考」角标
9. 不加水印、二维码、姓名生日等隐私信息
10. 交付前检查：无中英混排乱码、无孤字换行、无溢出截断

## 回复结构与交付判定

- 正文先给核心结论：一句话定性手型 + 点出最有表达价值的两条主线，然后按板块给出分组卡片或表格
- 「交付物」区块列出：线稿插图（PNG/SVG，如有）、HTML 报告；AI 生图成品（如走了通道 B）

## 边界

- 只处理用户本人主动提供的照片；涉及第三方的手相委托一律婉拒（建议由本人发起）
- 不可辨区域宁可空着写明，也绝不脑补细节冒充实测
