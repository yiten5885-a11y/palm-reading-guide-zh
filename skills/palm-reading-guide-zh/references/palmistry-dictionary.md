# 掌纹术语与解读映射字典

供 SKILL.md Step 2 文案阶段查阅。所有"解读方向"均为传统掌纹文化语境下的倾向性描述；最终成稿必须套用 §6 措辞库过滤一遍。

---

## 1. 四型手相（元素手型对照）

| 型 | 形态指纹 | 气质关键词 | 适用措辞例 |
|----|----------|-----------|-----------|
| 土型 / 方型 | 掌面方正宽阔、掌厚、指偏短 | 稳健、执行、组织 | "务实的底盘" |
| 水型 | 掌长指细、肉质柔软 | 敏感、想象、审美 | "感受力细腻的人" |
| 火型 | 掌长指短、气色偏暖 | 热情、冲劲、表达 | "自带行动派张力" |
| 风型 | 掌方指长、骨骼分明 | 思维、社交、信息 | "抽象思维的受益者" |

多数手是混合型：先写主导型（约七成特征吻合者），再用次要型补半句收尾。

## 2. 八丘速查

| 丘 | 位置 | 传统含义 | 高级措辞方向 |
|----|------|----------|-------------|
| 金星丘 | 拇指根部隆起 | 生命力、温度 | "生活热忱的蓄水池" |
| 月丘 | 掌缘小鱼际上部 | 想象、潜意识 | "内在图像的暗房" |
| 木星丘 | 食指根部 | 抱负、掌控欲 | "向上的牵引力" |
| 土星丘 | 中指根部 | 责任、自律 | "掌面的承重结构件" |
| 太阳丘 | 无名指根部 | 名望、审美回报 | "天赋被看见的区域" |
| 水星丘 | 小指根部 | 表达、商业嗅觉 | "随身自带的翻译器" |
| 上火星丘 | 食指下侧 | 抗压勇气 | "减震缓冲层" |
| 下火星丘 | 拇指对侧下缘 | 耐力持久 | "藏在底层的弹簧" |

写作提示：八丘只在隆起明显或明显扁平的时候写，普通状态不逐一点名。

## 3. 三大主线形态映射

### 3.1 生命线（地纹）

| 照片所见 | 解读方向 | 描述句式 |
|----------|----------|----------|
| 弧幅开阔、包绕金星丘宽 | 能量储备可观 | "围出一座宽敞的能量庭院" |
| 深而连续 | 体力与作息稳定 | "刻痕沉稳，笔力一贯到底" |
| 浅或断续 | 节奏波动 / 生活换挡 | "更像散文的分段呼吸感" |
| 起点贴近食指 | 视野与抱负外向 | "从高处起步的开阔视野" |
| 末端上翘收笔 | 恢复力强 | "收笔带回勾的弹性" |

### 3.2 智慧线（人纹）

| 照片所见 | 解读方向 | 描述句式 |
|----------|----------|----------|
| 平直贯穿 | 理性直线思维 | "像一台水平仪，误差很小" |
| 缓慢下斜 | 想象力、艺术取向 | "下滑的切线通往右脑展区" |
| 起点与生命线相并 | 谨慎、受家庭影响 | "同行一段再各自上路" |
| 与生命线完全分离 | 果敢自发 | "一出手就是自己的立场" |
| 末端分叉 | 双轨思考 | "一枝两叶的复合思维" |
| 锁链状、碎段 | 敏感、注意力分散 | "串珠式的敏感体质" |

### 3.3 感情线（天纹）

| 照片所见 | 解读方向 | 描述句式 |
|----------|----------|----------|
| 上拱止于食指与中指之间 | 理想主义情感观 | "一道望向高处的弧光" |
| 平直细长 | 务实、情绪克制 | "情绪管理的极简主义者" |
| 下垂切入智慧线附近 | 重情、共感强 | "与理性世界共享同一水位" |
| 分支细密 | 触角丰富 | "伸出许多细小的天线" |

## 4. 辅助线速查

| 线 | 位置 | 传统含义 | 写法 |
|----|------|----------|------|
| 命运线（玉柱纹） | 腕上纵向趋向中指 | 路径感与事业主线 | 清晰→"有迹可循的主干道"；缺席→"轨迹由几个阶段自由拼接，典型的非线性履历" |
| 太阳线（成功线） | 无名指下纵向短线 | 作品/声望回报 | 隐约→"后劲型的渐显线索" |
| 婚姻线 | 小指根下方横短线 | 亲密关系的样貌 | 只谈"关系相处气质"，绝不预测婚否 |
| 健康线 | 腕部斜向水星丘 | 生理节律提醒 | 有→"身体信号值得温柔留意"，配合免责句 |
| 腕带纹（手腕根横弧） | 腕横纹 | 底盘安定 | 通常一笔带过或不写 |

## 5. 五维综合框架

| 维度 | 主要依据 | 成稿要求 |
|------|----------|----------|
| 性格 | 手型 + 智慧线 | 一个关键词短语 + 1–2 句 |
| 事业 | 手型 + 命运线 | 指向工作风格，不指定行业成败 |
| 感情 | 感情线 (+婚姻线) | 相处气质，回避单身/离异等判断 |
| 财运 | 水星丘 + 太阳线 | 积累风格描述，不给数额暗示 |
| 健康 | 生命线 + 掌色纹理 | 只谈作息与节律习惯，禁病名 |

每维统一格式：**关键词**（2–4 字）+ 一句话注解。

## 6. 合规措辞库

积极倾向词（放心用）：倾向、气质、节奏、向往、张力、留白、蓄势、显影、渐显、余裕、锋芒、韧性、底盘、光谱

禁用词（出现即返工）：注定、必然、百分之百、凶、煞、克、灾、病、死、离异、破产、晚景凄凉

安全句模板：

- "传统掌纹观认为……，用现代的话说，它更像一种……的气质。"
- "这条线描绘的是倾向光谱，不是判决书。"

免责标准句（每份产出必须出现一次）：

> ✳ 内容源自传统掌纹文化的视觉化演绎，仅供文化与娱乐参考。

## 7. 无法辨认时的如实写法

- "受画面清晰度所限，该区域暂未展开。"
- "以下段落为通行示意讲解，并非针对您照片的实测结论。"

禁止在补充说明中悄悄把示意内容包装成实测。
