# AI 插图与排版提示模板

只在用户明确需要 AI 插画、背景或风格化线稿时读取。本模板用于视觉素材，不负责个体化掌纹判断。长段中文必须由 HTML/CSS 等确定性排版层渲染，不能依赖文生图模型拼字。

## 先选用途

### A 通用三大主线示意图

适合报告封面、教程和隐私优先场景。它不是用户掌纹复刻，图注必须写“通用位置示意”。

```text
极简编辑设计风格的手掌说明插画，纯白背景，一只五指自然张开的通用手掌轮廓，
均匀黑色细线，无阴影、无填充、无写实皮肤纹理、无身份特征。
掌面内只有三条清晰平滑曲线：
靠近指根的上方横弧、横贯掌心的中部曲线、环绕拇指根部的弧线。
构图居中，大量留白，像高端中文杂志的说明图标。
不要生成任何文字、字母、数字、标点、水印或二维码。
```

三条线的名称、编号和图注由排版层添加：感情线、智慧线、生命线。

### B 报告装饰背景

适合给 HTML 卡片增加轻微纸张质感，不得降低文字对比度。

```text
高端中文品牌白皮书的极简纸张背景，纯白到暖白，极轻微天然纸纹，
稀疏的黑色细线抽象弧形元素，只在边缘出现，中部保留完整干净留白，
平面编辑设计，克制、安静、现代。无文字、无手掌照片、无符号、无水印。
```

### C 风格化个人手形

只有用户明确要求把其照片转成风格化插图时才使用当前会话中的照片作为参考。不要为了处理而另行上传公开 URL。生成结果要标为“风格化插图”，不得称为掌纹实测或精确描摹。

```text
以所附手掌照片的外轮廓和手指姿态为参考，制作纯白背景的黑色细线风格化插图。
保留手指数目和大体轮廓比例；移除背景、饰品、纹身、肤色和可识别细节。
不要新增、补全或强化掌纹，不要生成文字、数字、水印或二维码。
```

若用户需要忠实个人线纹标注，不使用生成式插图替代证据；应在原图副本上叠加经视觉确认的标记，或者明确标注为通用示意。

## 中文长图排版参数

未指定平台时使用以下可复现默认值；用户给出平台、尺寸或品牌规范时优先遵守用户要求。

| 项目 | 默认值 |
|---|---|
| 画布 | 1080×1440 像素，3:4 竖版 |
| 外边距 | 72 像素 |
| 卡片间距 | 28–36 像素 |
| 卡片圆角 | 24–32 像素 |
| 描边 | 1–2 像素，浅灰 |
| 主标题 | 64–76 像素中文衬线字体 |
| 分区标题 | 36–44 像素 |
| 正文 | 不小于 28 像素，行高 1.55–1.75 |
| 配色 | 白底、墨黑主字、灰色辅助字；最多一种低饱和点缀色 |

内容装不下时拆成多张，不缩小到难以阅读。推荐拆分：封面与性质说明、观察范围、整体手型、三大主线、其他可见线纹、反思与边界。

## 成图检查

- 实际像素尺寸与用户要求一致。
- 中文文字由确定性排版层生成，无乱码、错字、孤字换行、裁切或溢出。
- 三大主线标签位置正确；通用线稿明确写“示意”。
- 性质说明在正常阅读尺寸下可见，不隐藏在角落小字。
- 生成式插图没有增加额外手指、伪造个人纹路或暴露原图背景。
- 输出文件已实际打开检查；生成提示词或 HTML 代码不等于图片交付。
