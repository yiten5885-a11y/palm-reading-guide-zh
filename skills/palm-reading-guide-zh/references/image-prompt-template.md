# AI 生图提示词模板（文生图 / 图生图通用）

前置铁律：**文字越少越稳**。生图模型直出长中文的乱码率极高，每张图只承担一个板块；长文案一律走 HTML 通道。

## 0. 参数基线

| 项 | 值 |
|----|----|
| 比例 | 3:4 竖构图（小红书/公众号封面）；手机长图用 9:16 |
| 风格锚点 | 极简、高级感、咨询报告、杂志内页、大量留白、editorial minimalism、thin line art |
| 色彩 | 白底 `#FFFFFF` + 墨黑 `#111`，至多一种点缀色（warm gold 或 cinnabar） |

## 模板一 · 整页解析卡（可选通道 B）

```
[正向]
杂志级极简排版海报，3:4 竖版，纯白色背景 (#FFFFFF)，
细黑线描边卡片与圆角矩形分区，大量留白；
顶部居中大号衬线中文标题「你的手相解析指南」，下方一条极细分隔线；
中部一只黑色细线勾勒的手掌图标；
下方三张圆角细线卡片，小标题分别为「01 手型」「02 主线」「03 综合」，
每张卡片仅一到两行细体中文短句；
底部居中一行小字「仅供文化娱乐参考」。
整体气质：高端杂志内页、品牌白皮书、留白呼吸感。
{{ACCENT_COLOR}}（可省略；填：点缀色为暖金色 / 朱砂红）

[负向]
彩色渐变、厚重阴影、复杂装饰、花哨边框、水印、错别字、扭曲变形的文字、密集长段落
```

约束自查：全文块数 ≤6、单块 ≤12 个汉字。超了就砍内容交回 HTML 通道。

## 模板二 · 黑白线稿手掌示意图（插图专用，零文字依赖）

```
[正向]
极简设计图标风格说明插画，纯白背景，
一只五指自然张开的手掌黑色细线稿（thin line art，均匀描边约1.5px，
无阴影、无填充色、无写实皮肤纹理），
掌面内三条平滑黑色曲线：
一条环绕拇指根部的宽弧代表生命线，
一条横贯掌心的长弧代表智慧线，
一条靠近指根的上拱弧线代表感情线，
三个小圆圈序号①②③分别落在这三条线上；
构图居中，干净克制，品牌说明插画质感。

[负向]
颜色、渐变、阴影、写实皮肤、指甲细节毛刺、背景装饰、任何文字与字符
```

注意：

- 序号 ①②③ 若生成变形，裁掉重生成一次；仍失败则改由 HTML/SVG 层叠加编号
- 面向"示意图"定位交付时必须在图注写明"示意"，不可暗示为用户实测复刻

## 从六要素到提示词（组装步骤）

1. 用户原图为正面摊掌、光线均匀 → 走图生图：上传原图 + 模板二正向词，并追加约束
   `保持原图手指数目、姿态与掌形比例不变`
   ——让线稿贴合用户的真实掌形而非通用手套
2. 原图角度差或纹理难辨 → 直接文生图通用构型，成品标注"示意图"
3. 出图质检三条：线条闭合干净 / 无乱码无字符 / 曲线位置符合三大主线通行走向；不合格重掷一次，两连败切回模板内置 SVG

## 与 HTML 通道的分工

- 生图：只画形状与线，不承载信息密度
- HTML：标题、正文、免责角标、图文合成排版
